due to licensing restrictions. Follow the instructions below to download each resource.

## 2. BILMA Dialectal Vocabulary

**Source:** Tellez et al. (2022) — Regional Spanish Models  
**License:** Apache 2.0  
**URL:** https://ingeotec.github.io/regional-spanish-models/

Download the TSV files for each dialect:

```bash
mkdir -p data/bilma
# Download each dialect file
for code in MX AR CL CO ES PE US; do
    wget -P data/bilma/ \
        "https://ingeotec.github.io/regional-spanish-models/data/${code}.tsv"
done
```

Each file has the following format:

```
token    occs    ndocs    weight
güey     91823   47201    2.847
chido    38421   21004    2.103
...
```

Then build the vocabulary:

```bash
python scripts/build_vocabulary.py \
    --bilma-dir data/bilma/ \
    --output data/vocabulary.json \
    --min-freq 5
```
